# 基于遗传算法的移动机器人路径规划 —— 详细文档

## 1. 项目概述

本项目使用 **遗传算法（Genetic Algorithm, GA）** 为二维静态环境中的移动机器人规划最优路径。目标是从起点（节点 0）到达终点（节点 15），在不与 7 个多边形障碍物发生碰撞的前提下，找到一条总距离最短的路径。

地图预定义了 **16 个路径点** 及其之间的 **允许连接关系**（邻接图）。每条染色体（候选解）是由节点索引组成的一条路径序列。

### 5.2 主循环代码 (`main.py`)

```python
def main():
    # 1. 初始化
    chr_population = population()
    chr_pop_fitness, chr_best_fitness_index = fitness(chr_pop=chr_population)
    chr_ranked_population = ranking(chr_pop_fitness=chr_pop_fitness, pop=chr_population)
    chr_crossover_mutated_population = dna(...)

    # 2. 迭代进化
    while not Config.stop_generation:
        prev_best_fit = chr_pop_fitness[chr_best_fitness_index[0], 0]
        chr_pop_fitness, chr_best_fitness_index = fitness(...)
        chr_ranked_population = ranking(...)
        chr_crossover_mutated_population = dna(...)

        # 3. 收敛检测
        if prev_best_fit == chr_pop_fitness[chr_best_fitness_index[0], 0]:
            Config.stop_criteria += 1
        else:
            Config.stop_criteria = 0

        if Config.stop_criteria >= 5:
            Config.stop_generation = True

        show_plot(...)
```

**收敛条件**: 当最优适应度连续 5 代没有提高时，算法停止。

## 6. 模块详解

### 6.1 种群初始化 (`tools/population.py`)

#### 核心思想

使用 **偏置随机游走** 生成初始种群。每条路径从起点出发，每次根据各可选连接的 **距离倒数概率** 选择下一节点，直到到达终点。这种初始化方式使得初始种群倾向于选择较短的边，提高了初始种群的质量。

#### 函数说明

| 函数 | 功能 |
|------|------|
| `population()` | **入口函数**。依次计算连接距离、连接概率、累积概率，然后生成初始种群。 |
| `_link_distance(link)` | 计算邻接矩阵中每对相邻连接的 **欧氏距离**。 |
| `_link_prob(link_fit)` | 将每条边的距离转换为选择概率。公式：`P(i→j) = dist(i,j) / Σ dist(i,*)` |
| `_create_pop(link_cum_prob)` | 基于累积概率为每个染色体构造路径。对每个基因位，生成随机数 r ∈ [0,1)，根据 CDF 区间选择下一节点。到达终点后，剩余位置填充终点。 |
| `calculate_distance(pt_1, pt_2)` | 计算两点间的欧氏距离：$d = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}$ |

#### 概率采样示例

假设节点 A 可连接到节点 B、C、D，连接距离分别为 3、5、8：

```
P(A→B) = 3 / (3+5+8) = 3/16  = 18.75%  → CDF [0, 0.1875)
P(A→C) = 5 / 16          = 31.25%  → CDF [0.1875, 0.5)
P(A→D) = 8 / 16          = 50.00%  → CDF [0.5, 1.0)
```

生成随机数 r = 0.3 时选择 C；r = 0.7 时选择 D。

### 6.2 适应度评估 (`tools/fitness.py`)

#### 核心思想

采用 **双组件适应度函数**，同时考虑路径长度和连通合法性：

$$\text{fitness} = \text{distance\_fitness} + \text{connectivity\_fitness}$$

#### 函数调用链

```
fitness(chr_pop)
  ├── chr_pts_consecutive_dist(pop)         → 每步的距离
  │     └── chr_fit_based_dist(...)         → 距离适应度
  ├── chr_conn(chr_pop)                     → 有效连接数
  │     └── chr_fit_based_conn(...)         → 连通适应度
  ├── chr_fit(dist_fit, conn_fit)            → 最终适应度
  └── chr_best_fit_ind(chr_fit)             → 前3最优索引
```

#### 各函数详解

| 函数 | 公式 | 说明 |
|------|------|------|
| `chr_pts_consecutive_dist(pop)` | $d_i = \sum_{j=1}^{\text{len}-1} \|P_{c[j]}, P_{c[j-1]}\|$ | 每条染色体相邻节点间的欧氏距离 |
| `chr_fit_based_dist(...)` | $f_d = 10.0 \times \frac{1}{d_i}$ | 距离适应度 = 10 / 总距离。距离越短越高，缩放因子 10 用于平衡与连通分量的数值 |
| `chr_conn(chr_pop)` | — | 遍历染色体的相邻节点对，若在邻接矩阵中存在对应连接则 +1 |
| `chr_fit_based_conn(...)` | $f_c = \frac{\text{valid\_edges}}{\text{chr\_len} - 1}$ | 连通适应度 = 有效边数 / 总边数。最大值 1.0 表示所有相邻节点都合法连通 |
| `chr_fit(dist_fit, conn_fit)` | $F = f_d + f_c$ | **最终适应度** = 距离适应度 + 连通适应度 |
| `chr_best_fit_ind(chr_fit)` | — | 迭代 3 次找出适应度最高的 3 个染色体索引，每次找到后将其适应度清零 |

### 6.3 轮盘赌选择 (`tools/ranking.py`)

#### 核心思想

采用 **适应度比例选择（Fitness Proportionate Selection）**，也称轮盘赌选择。适应度越高的个体被选中的概率越大。

#### 函数调用链

```
ranking(chr_pop_fitness, pop)
  ├── cal_prob(chr_pop_fitness)             → 计算选择概率
  ├── np.cumsum(chromo_prob)                → 累积概率
  ├── _ranking_based_on_roulet_wheel_selection(cum_prob) → 轮盘赌抽样
  └── _generate_mating_pool(rank, pop)      → 生成交配池
```

#### 各函数详解

| 函数 | 说明 |
|------|------|
| `cal_prob(chr_pop_fitness)` | 归一化适应度：$P(i) = \frac{F_i}{\sum_{j=0}^{N-1} F_j}$ |
| `_ranking_based_on_roulet_wheel_selection(cum_prob)` | 生成 `pop_max` 个随机数 r ∈ [0,1)，通过 CDF 查找对应的染色体索引。每个染色体被选中的次数组合成排名字段 `chr_rank[i]`。 |
| `_generate_mating_pool(rank, pop)` | 根据每个染色体的 `rank` 值（被选中的次数），在交配池中复制相应份数。适应度高的个体会被多次复制。 |

#### 轮盘赌选择示例

```
染色体  适应度    概率     累积概率  区间
  A      10       0.25      0.25     [0, 0.25)
  B      20       0.50      0.75     [0.25, 0.75)
  C      10       0.25      1.00     [0.75, 1.00)

随机数 r = 0.15 → 选 A
随机数 r = 0.40 → 选 B
随机数 r = 0.90 → 选 C
```

### 6.4 交叉与变异 (`tools/dna.py`)

#### 核心思想

`dna()` 函数先执行交叉，后执行变异，返回新一代种群。

```
dna(chr_pop_fitness, ranked_population, chr_best_fitness_index, last_pop)
  ├── _do_crossover(ranked_pop, chr_best_fit_indx, pop)  → 交叉
  └── _do_mutation(pop)                                   → 变异
```

#### 6.4.1 交叉 (`_do_crossover`)

采用 **精英保留 + 单点交叉** 策略：

1. **精英保留（Elitism）**: 前 3 个位置直接复制上一代适应度最高的 3 条染色体，防止最优解丢失。

2. **单点交叉（Single-Point Crossover）**: 第 4 到第 `pop_max/5`（即前 20%）的染色体通过交叉产生：
   - 从交配池中随机选择两个父代（partner_a, partner_b）
   - 随机选择一个交叉点 `joining_pt ∈ [0, chr_len-1]`
   - 子代 1 = partner_a[0:join] + partner_b[join:]
   - 子代 2 = partner_b[0:join] + partner_a[join:]

3. **直接复制**: 剩余 80% 的染色体直接从交配池复制。

```
交叉示例 (chr_len = 9):
  交叉点 = 4

  父代A: [0, 1, 2, 5, 10, 11, 12, 15, 15]
  父代B: [0, 3, 6, 7, 9,  10, 11, 12, 15]

  子代1: [0, 1, 2, 5,  9, 10, 11, 12, 15]   ← A前4 + B后5
  子代2: [0, 3, 6, 7, 10, 11, 12, 15, 15]    ← B前4 + A后5
```

#### 6.4.2 变异 (`_do_mutation`)

**重置变异（Reset Mutation）**:

- 范围：第 4 到第 `pop_max - 1` 条染色体（跳过前三精英）
- 对每个基因位（除 `k = 0` 即起点外），以 `mutation_rate = 0.01` 的概率将其重置为 `[1, npts-2]` 范围内的随机节点索引
- 这是一种随机重置策略，而非高斯或多项式扰动

> **注意**: `k is not 0` 使用的是身份比较而非值比较，但由于 `k` 始终是 Python 整数且在 `0-8` 范围内，CPython 的小整数缓存保证了比较行为的正确性。

## 7. 数学公式汇总

| 名称 | 公式 |
|------|------|
| **欧氏距离** | $d(p_1, p_2) = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$ |
| **连接概率 (初始化)** | $P(i \rightarrow j) = \dfrac{d(i, j)}{\sum_{k} d(i, k)}$ |
| **距离适应度** | $f_d = \dfrac{10}{\sum \text{path\_distance}}$ |
| **连通适应度** | $f_c = \dfrac{\text{valid\_connections}}{\text{chr\_len} - 1}$ |
| **最终适应度** | $F = f_d + f_c$ |
| **选择概率 (轮盘赌)** | $P_{\text{select}}(i) = \dfrac{F_i}{\sum_{j=1}^{N} F_j}$ |

## 11. 算法特点与局限性

### 优点
- **偏置初始化**: 使用距离倒数概率的随机游走，初始种群质量较高
- **双组件适应度**: 同时优化距离和连通性，避免生成不可行路径
- **精英保留**: 确保最优解不会因交叉/变异而退化
- **自适应终止**: 基于停滞检测自动停止，无需预设代数

### 局限性
- **硬编码环境**: 路径点、障碍物、连接图均在代码中硬编码，不易扩展到新地图
- **无碰撞检测**: 适应度函数未直接检测路径与障碍物的交叉（依靠连接图隐式保证避障，因为合法连接本身绕过障碍物）
- **简单变异**: 仅使用随机重置变异，缺乏精细化局部搜索能力
- **无路径平滑**: 输出的路径是折线段，未做平滑后处理
- **收敛可能过早**: 精英策略 + 停滞检测可能导致过早收敛到局部最优

---

## 12. 扩展建议

1. **通用化环境**: 将路径点、连接图、障碍物提取为外部配置文件（JSON/YAML）
2. **碰撞检测**: 在适应度函数中加入显式碰撞惩罚项
3. **路径平滑**: 对最终路径应用贝塞尔曲线或 B 样条平滑
4. **多目标优化**: 同时优化路径长度、能量消耗、安全裕度
5. **自适应参数**: 使交叉率和变异率随代数动态调整
6. **并行化**: 使用多进程加速适应度计算
